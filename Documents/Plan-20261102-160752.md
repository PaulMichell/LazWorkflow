# Rename Close plan controls

Generated by Lazarus Project Assistant.

The plan sheet and the phone Plan screen already say Close. That action clears the active plan and leaves the file in the available list. The identifiers, the wire command, and one unused layout still say Remove. A second, smaller clash is the phone menu method `openPlan`, which sends `select_plan` rather than opening the document.

Rename in place. Do not change behaviour, busy rules, captions that already say Close, or catalogue version. Do not accept `remove_plan` as an alias. An old phone and a new IDE will disagree on this one command until both are updated. Do not reorder `TMonitorMessageKind` or `MessageKind`.
