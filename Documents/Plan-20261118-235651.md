## 1. Form component editing

### 1.1 Bind generated members to the form named by the LFM

Status: complete

A helper class preceding the form can receive the generated members while the LFM attaches the component to the form. A same-named field elsewhere can suppress insertion entirely.

Check with a helper class declared first and a same-named member on that helper. Compile the edited unit and stream the form to verify the component field and event binding.

## 2. Dictionary discovery

### 2.1 Drain Aspell output while the process runs

Status: not started

`Source/LazWorkflowCommon/SpellEngineAspell.pas:219–230` starts `aspell dump dicts` with pipes and `poWaitOnExit`, then reads stdout once into a 65,536-byte string. A full pipe can leave the child waiting for the parent to read while the parent waits for exit. A single read can also return an incomplete list.

Drain stdout and stderr during execution, keep diagnostics separate from dictionary names, and check the exit status before publishing the list. Remove the redundant empty-string assignment immediately before buffer allocation. Verify with a fixture process that emits more than 64 KiB in chunks, including a recognisable final dictionary, and another that exits with an error.
