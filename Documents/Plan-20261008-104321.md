# Tidy Up Plan

Generated by Lazarus Project Assistant.

Remove leftover command-style chrome from Project Assistant, then unused menus and unexposed actions, then unreachable Pascal. The visible window must behave as it does now: composer buttons, mode combobox, History and Plan sheets, prompt and attachment popups, status footer, Settings, image and Markdown viewers, and the IDE Assistant menu.

Do the packages in order. Each later package assumes the earlier deletions have landed, then re-checks callers before deleting anything else. Do not delete a symbol because an old report named it. Re-read the current `.pas` and `.lfm` in the same edit.

Path and URL helpers whose names contain "Slash" are not a command interface. Leave `NormalSlashPath`, `TrimSlash`, `SlashPos`, and the image-path `Slash` loop alone.

- Settings `AddConnectionMenu`.

- `TSpellMemo` edit and spelling popups.
- Repository `GitDiffView.Popup` (Copy has a shortcut; stage and unstage items are live) and `ManageRepositoryForm.Popup`.
- The IDE `&Assistant` menu registered in `AssistantMain.pas` (Project Assistant, Open Markdown, Review Compile, Review Build, Fix Error, Settings). That is the IDE menu, not `AssistantMenu`.

## 3. Unexposed actions

An action stays only when a visible control has `Action =` that action, a live popup item or shortcut runs it, or a visible control calls its `OnExecute` method. The detached form menu does not count. A keyboard shortcut counts only when it is assigned and can fire (Markdown Open, Save, Preview, Source, image Close, diff Copy, prompt edit keys).

Keep these Project Assistant actions. The footer calls the execute methods directly, so they are exposed even though the footer does not set `Action =`:

- Composer: `NewConversationAction`, `NewPlanAction`, `RunPlanAction`, `SettingsAction`, `SendAction`, `StopAction`.
- History sheet: `ExportHistoryAction`, `DeleteHistoryAction`.
- Plan sheet: `OpenPlanSheetAction`, `RemovePlanAction`.
- Attachment popup: `AttachImageAction`, `RemoveAttachmentAction`, `SaveAttachmentAction`, `PreviewAttachmentAction`.
- Footer: `ModelPickerAction`, `SkillsPickerAction`, `ContextBreakdownAction`, `SessionInfoAction`.

Keep Markdown and image actions. Re-read `ManageRepositoryForm` before touching its actions; the current resource binds them to buttons or the history popup. Leave any that are still bound.
